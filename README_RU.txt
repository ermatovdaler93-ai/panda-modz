# Panda Modz — готовый проект сайта

## Что есть
- Главная страница активации: `/`
- Панель администратора: `/admin`
- Серверная проверка ключей и лимита устройств
- Создание ключей на 1/7/30/90/365 дней или навсегда
- Поиск, фильтры, CSV, отзыв и удаление ключей
- Хранение данных в `data/keys.json`

## Запуск на компьютере
Нужен Node.js 18 или новее:
1. Распакуйте архив.
2. Откройте терминал в папке проекта.
3. Выполните `npm install`
4. Установите переменную окружения `ADMIN_PASSWORD` (пароль панели).
5. Выполните `npm start`
6. Откройте `http://localhost:3000`, панель — `http://localhost:3000/admin`.

## Публикация
Загрузите папку проекта в GitHub и создайте на хостинге веб-сервис из репозитория:
- Build command: `npm install`
- Start command: `npm start`
- Environment variable: `ADMIN_PASSWORD` = ваш длинный пароль
- Для постоянного хранения добавьте persistent disk и задайте `DATA_DIR` как путь диска (например `/var/data`).

Не публикуйте пароль администратора в HTML или GitHub. Не используйте простой пароль.
Если хостинг не поддерживает постоянный диск, ключи могут пропасть после перезапуска/переразмещения.
Перед использованием для реальных клиентов проверьте HTTPS, резервное копирование и правила хранения данных.
